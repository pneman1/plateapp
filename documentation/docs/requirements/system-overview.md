# System Overview

## Project Abstract

The Plate App is a social, real-time food discovery application. It utilizes a "Live-Only" photo capture mechanism to ensure authenticity. The system leverages geolocation to create a community-driven map of local food while maintaining a "Social Lock" on friend content to encourage daily participation.

Once you share a picture of your meal onto the app, you'll be able to observe meals submitted by friends, or other public users through the app.
